# Glossary

Short explanations of the abbreviations and project terms used in these docs. Each term links to the page that covers it.

## TortoiseBots terms

| Term | Meaning |
| :--- | :--- |
| **Pool bot** | A random bot that lives in the world on its own: it levels, quests and wanders. See [The kinds of bots](getting-started.md#the-kinds-of-bots). |
| **Own alt** | A character on your own account that you log in as a bot with `.bot add`. |
| **Hired companion** | A temporary bot hired at a recruiter; it is deleted when you dismiss it, log out, or leave the party (plus a short disconnect grace). See [`.bot hire`](commands/roster-and-hiring.md#bot-hire). |
| **Alt-bot** | One of your alts that keeps playing on its own after leaving your group. Level 10 and up: teleported to a zone that fits its level. See [Alt-bots](commands/roster-and-hiring.md#alt-bots-autonomous-alts). |
| **Master** | The player a bot follows and takes orders from. |
| **Capital recruiter** | One of the six capital-city NPCs where you can hire companions; level-60 characters can also buy world buffs and mercenary contracts there. See [Capital recruiter services](commands/roster-and-hiring.md#capital-recruiter-services). |
| **Pullback** | A pull where the tank tags a pack and runs back around a corner, so the mobs come to the group out of line of sight. See [`.bot action pullback`](commands/party-actions.md#bot-action-pullback). |
| **Remote commander** | A mode where you steer a bot-only party from afar (a bound raid, or a few real players staying in the party). See [Remote commander](commands/commander.md). |
| **Managed pool** | The set of bot accounts the server creates and manages for pool bots. See [Bot pool](../server/bot-pool.md). |
| **Setting / feature flag** | A line in `aiplayerbot.conf` (plus `tortoise_bots.conf`) that turns a feature on or off or tunes it. Most keys need a restart. See [How configuration works](../server/configuration.md). |
| **TBM** | TortoiseBotsManager, the in-game addon opened with `/tbm`. See [Addon](commands/addon.md). |

## Abbreviations

| Short | Meaning |
| :--- | :--- |
| **AH** | Auction House. |
| **AB / AV / WSG** | Arathi Basin, Alterac Valley, Warsong Gulch (battlegrounds). |
| **AoE** | Area of effect: a spell that hits everything in an area. |
| **BG** | Battleground. |
| **CC** | Crowd control: keeping a mob out of the fight with Sheep, Sap, Shackle and similar spells. |
| **CD** | Cooldown. |
| **DND** | "Do not disturb" chat status (`/dnd`). |
| **DPS** | Damage dealer (damage per second). |
| **GCD** | Global cooldown. |
| **GM** | GameMaster: a server administrator account. |
| **GUID** | The unique number the server gives every character, creature and object. |
| **LFT** | Looking for Turtles, the Tortoise WoW dungeon finder. |
| **LoS** | Line of sight. |
| **NPC** | A creature or character controlled by the server, not by a player. |
| **XP** | Experience points. |
